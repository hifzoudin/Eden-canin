# Eden Canine

Eden Canine is a premium French breeder storefront dedicated to Border Collies and Poodles. The project presents the kennel with a refined boutique aesthetic, multilingual content, and a direct WhatsApp-based buying experience.


## Overview

This application was created to showcase the breeding program, highlight available puppies, communicate the kennel’s values, and guide interested families through a simple and transparent contact and purchase process.

## Main features

- Elegant storefront for the kennel
- Puppy catalogue with details and filters
- Shopping cart and purchase flow
- Contact page with WhatsApp integration
- About page presenting the breeding philosophy and commitments
- Multi-language support: French, English, German
- Responsive layout for desktop and mobile

## Tech stack

- React
- Vite
- React Router
- Local state management for cart and storefront data

## Project structure

- `src/components` — reusable UI elements such as the header, footer, cards, and contact actions
- `src/context` — cart, language, and storefront state providers
- `src/pages` — public pages including Home, About, Puppies, Contact, FAQ, Legal and Checkout
- `src/translations` — French, English and German dictionary files
- `src/data` — catalog and default storefront data
- `public` — static assets, including the brand logo

## Brand identity

Eden Canine represents a modern, professional, and humane breeding experience: health-focused, transparent, and close to the families who adopt a puppy.

## Contact and purchase flow

The website is designed to support a direct, personal relationship with the breeder through WhatsApp, keeping the buying process simple, clear, and trustworthy.
